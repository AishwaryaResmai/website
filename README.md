## 4. The 9 Core Portfolio Services

1. **Personal Loan Collections**: Unsecured retail loans resolution across early to late delinquency buckets with structured repayment counseling.
2. **Credit Card Collections**: High-velocity recovery for revolving credit cards, minimizing roll-rates and recovering charge-offs.
3. **Business Loan Collections**: SME/MSME delinquent debt resolution, promoter consultations, and cash-flow recovery plans.
4. **Consumer Loan Collections**: Durables, appliance financing, and retail point-of-sale debt resolution.
5. **X-Sell Collections**: Pre-approved loans and top-up facility delinquent recovery with targeted borrower communication.
6. **Two-Wheeler Loan Collections**: Retail auto and 2-wheeler asset tracing and in-person field verification.
7. **Skip Tracing**: Lawful location intelligence, workplace checks, and address restoration for absconding accounts.
8. **Outstation Field Visits**: Deep ground penetration across Tier-2, Tier-3, and rural clusters across Telangana and Andhra Pradesh.
9. **Portfolio Monitoring and Supervision**: End-to-end delinquency bucket surveillance, weekly performance reviews, and compliant payment settlement discussions.

## 5. How to Run Using Visual Studio Code & Live Server

### Method 1: Using VS Code Live Server Extension (Recommended for Visual Editing)
1. Open **Visual Studio Code**.
2. Go to **File > Open Folder...** and select `C:\Users\DELL\New folder\aishwaryaaa`.
3. In the VS Code Extensions panel (`Ctrl + Shift + X`), ensure **"Live Server"** (by Ritwick Dey) is installed.
4. Right-click on [`index.html`](file:///c:/Users/DELL/New%20folder/aishwaryaaa/index.html) in the file explorer and select **"Open with Live Server"**.
5. Your default browser will automatically launch at `http://127.0.0.1:5500/index.html` with real-time hot reloading on every save.

### Method 2: Zero-Dependency Node.js Server
No `npm install` required! Run directly from PowerShell or terminal:
```powershell
node server.js
```
Then open `http://localhost:3000`. Form submissions will automatically log into `data/enquiries.json`.

### Method 3: Python 3 Standard Library Server
```powershell
python app.py
```
Then open `http://localhost:3000`.

### Method 4: Double-Click Directly
Double-click `index.html` to open in Google Chrome, Microsoft Edge, or Firefox. All fonts, styles, SVG icons, and interactions operate standalone offline.
